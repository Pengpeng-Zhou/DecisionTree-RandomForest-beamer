# 决策树与随机森林（理论篇）

机器学习入门 Beamer 幻灯片：决策树与随机森林，共 40 页，风格与 DID-beamer 模板一致（深红主题、miniframes 顶栏、XeLaTeX 编译）。

- 作者：Pengpeng Zhou
- 机构：北京工商大学　经济学院
- 邮箱：m3126211047@163.com

## 内容

1. 基本概念：特征与目标、分类与回归、树结构、参数与超参数
2. 分类决策树：Gini 不纯度、加权切分、金融算例、数值阈值、多分类、预测
3. 回归决策树：MSE、叶节点取均值、切分与预测
4. 超参数与剪枝：预剪枝、成本复杂度后剪枝、过拟合
5. 随机森林：Bootstrap、特征抽样、硬/软投票、多分类、回归、降方差
6. 损失函数与金融实践：时间泄漏、类别不平衡、概率校准、特征重要性
7. 模型对比与学习路线：与提升树对比、完整学习流程

## 编译

需要 XeLaTeX（TeX Live），连编两遍以生成目录、顶栏进度点和页码：

```bash
xelatex main.tex
xelatex main.tex
```

中文支持自动判断：装有 ctex 时走 Fandol 宋体，否则退回 fontspec + 思源宋体。
